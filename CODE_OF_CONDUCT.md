# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of
conduct: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: we want participation in this project to be a harassment-free
experience for everyone. Be respectful, assume good intent, accept
constructive feedback gracefully, and focus on what is best for the
community. Harassment, insults, sexualized language or imagery, publishing
others' private information, and other conduct that would be inappropriate in
a professional setting are not acceptable.

The code of conduct applies in all project spaces (issues, pull requests,
discussions, chat) and when someone represents the project in public.

## Reporting

Report unacceptable behaviour to the maintainers at
**CONDUCT-CONTACT-TO-BE-SET-BEFORE-LAUNCH**. Reports are handled
confidentially. Maintainers will follow the Contributor Covenant's
enforcement guidelines (correction, warning, temporary ban, permanent ban)
when deciding on consequences.
