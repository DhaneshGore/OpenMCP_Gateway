# Getting help

* **Usage questions:** open a GitHub Discussion (or an issue labelled
  `question` if Discussions are not enabled).
* **Bugs:** open an issue using the bug report template. Please include
  `openmcp --version`, the output of `openmcp doctor`, and your configuration
  with secrets removed.
* **Feature ideas:** open an issue using the feature request template and
  describe the problem you're solving, not just the solution.
* **Security issues:** follow [SECURITY.md](SECURITY.md). Never use a public issue.

This is a volunteer-run project; there is no commercial support and no
response-time guarantee. [docs/troubleshooting.md](docs/troubleshooting.md)
answers the most common questions.
